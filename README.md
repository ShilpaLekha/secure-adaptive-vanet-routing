# secure-adaptive-vanet-routing

# Secure Adaptive Multi-Strategy Routing in Heterogeneous VANETs

M.Tech Research Project

## Dataset

roadNet-CA dataset from SNAP:
https://snap.stanford.edu/data/roadNet-CA.html

## Features

- Heterogeneous node classification
- Dynamic attacker mobility
- Mutual authentication
- Direct Avoidance Routing
- K-Shortest Routing
- Weighted Random Routing
- Node Disjoint Routing
- Dynamic rerouting

## Requirements

pip install -r requirements.txt

## Run

python main.py

## Performance Metrics

- Packet Delivery Ratio (PDR)
- Energy Consumption
- End-to-End Delay
- Throughput
- Attack Evasion Rate
